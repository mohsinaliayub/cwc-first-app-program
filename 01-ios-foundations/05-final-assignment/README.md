# Assignment
The assignment is purposely open ended so encourage you to explore on your own using the skills you've learned and practiced in this course. The only requirements are the ones listed below. 


## Requirements
- Uses either drill down or tabbed navigation.
- Reads and parses JSON from a json data file that you created.
- Must display a scrollable list of items. You can use any technique you want (List, ForEach, Grid etc).
- The app must have more than 1 screen. 
- The app must use at least 1 image asset that you've included in the Xcode Asset Library.
- The app must not crash when being used in the iOS Simulator.


## Goal
The goal is to be able to:
- Build an app on your own, and
- Solidify the knowledge that you've gained during the course.
