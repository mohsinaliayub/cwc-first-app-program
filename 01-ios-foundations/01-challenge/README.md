# Number Climb Game
A simple challenge to test your understanding of the basics of SwiftUI and Swift. 


## Challenge
- Build a UI that contains a Text element at the top and a Button below it.
- The Text element should initially display "0".
- Declare a function increase() that adds a random number between 1 and 10 to the number displayed in the Text element.
- Declare a function decrease() that subtracts a random number between 1 and 10 from the number displayed in the Text element.
- Create a state variable to keep track of the current number displayed.
- Initially, when the button is tapped, it should call the increase() function.
- When the number displayed goes over 50, the button should start calling the decrease() function.
- When the number displayed goes below 0, the button should revert to calling the increase() function.


## Goal
The number displayed should cycle: increase to above 50, then decrease to below 0, then increase again, and so on.
