# iOS Foundations
This repo contains the walkthrough projects, challenges and a final assignment from the **iOS Foundations** course offered by [Code with Chris](https://codewithchris.com/).

## Skills Learned
This course teaches the following fundamental skills to a beginner iOS developer:
- How to build 3 different types of Apps (**single screen, tabbed, drilled down**)
- Xcode (**Debugging, Canvas, Simulator, Navigator, Inspector**)
- Swift (**variables, constants, functions, structures, loops, if-statements, closures, arrays, dictionaries, call throwable functions**)
- SwiftUI (**Basic Elements, Containers, ForEach, GeometryReader, Modifiers**)
- Misc. (**JSON, code reusability, modeling data**)
