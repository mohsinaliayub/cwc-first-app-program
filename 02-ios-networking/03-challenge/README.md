# Football Stats
A simple app that downloads data from a Football API and display a list of teams to test your understanding of the basics of Networking. 

## Setup
- Football Data [API](https://www.football-data.org/) (Create a free account)
- Endpoint: 
  - https://api.football-data.org/v4/teams
- Documentation:
  - [API Documentation](https://learn.codewithchris.com/courses/take/networking/lessons/55721784-module-2-challenge-football-stats-app#:~:text=Documentation-,API%20Documentation,-Authentication%20Documentation%20(Use))
  - [Authentication Documentation](https://learn.codewithchris.com/courses/take/networking/lessons/55721784-module-2-challenge-football-stats-app#:~:text=Authentication%20Documentation) (Use X-Auth-Token as a request header)
  - [Rate Limits and Quotas Documentation](https://docs.football-data.org/general/v4/policies.html)
  - [Values for parameters](https://docs.football-data.org/general/v4/lookup_tables.html)

## Challenge
- Build a UI that has a List view and a Button at the bottom. 
- When the button is tapped, send the request to fetch the teams.
- When the response returns, parse the data and display the team names in the List view
- Make sure you use "async" and "await" as you learned in Lesson 5 of Module 1.
- Make sure you store your API key in a Config file as you learned in this module.


## Goal
Display a scrollable list of football teams.
