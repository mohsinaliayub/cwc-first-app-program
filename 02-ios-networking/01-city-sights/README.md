# City Sights
A very simple app that displays a list of city sights fetched from Yelp. 


## SwiftUI Views

The following views are used in creating the UI of the app:
- HStack
- Image
- Text
- List


## SwiftUI Modifiers
The following modifiers are used:
- resizable()
- aspectRatio(contentMode:)
- font(_:)
- frame(height:)
- frame(maxWidth:alignment:)
- listRowSeparator(:)
- listRowBackground(:)
- listStyle(:)
- onAppear(:)



## Swift & Miscellaneous 
The following extra concepts are used to make the app logic work:
- @State
- Variables (**var**)
- Constants (**let**)
- Functions (**func**)
- Structures (**struct**)
- Data service
- Arrays


Above views, modifiers and concepts are the entirety of this simple app.
