# iOS Networking
This repo contains the walkthrough projects, challenges and a final assignment from the **iOS Networking** course offered by [Code with Chris](https://codewithchris.com/).



## Skills Learned
This course teaches the following fundamental skills to a beginner iOS developer:
- Extend your skills from **iOS Foundations** course. 
- Hone and further your skills in the three core areas of **Xcode**, **Swift** and **SwiftUI**.
- Connect to other platforms for data through APIs. (**Network requests**)
- Learn about modern Swift concurrency and how to make your apps more performant. (**async, await, Task**)
